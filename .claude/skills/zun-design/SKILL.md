# ZUN 디자인 — 웹앱에 붙이는 판

인스타 계정 **@zun_it_** 의 카드뉴스·릴스에서 실제로 쓰고 있는 값입니다.
지어낸 값이 하나도 없습니다 — 카드 렌더러(`cardnews/render.py`)와 대시보드
(`web/index.html`)에 박혀 있는 것을 그대로 떠 왔고, 대비는 **재서** 적었습니다.

**왜 옮겨 적나:** 앱마다 색을 새로 고르면 계정과 앱이 갈라집니다. 릴스에
앱 화면이 나가는데 그 화면이 다른 브랜드처럼 보이면, 릴스 한 편이 두
브랜드를 보여주는 셈입니다.

> 다른 레포에 붙일 때는 이 파일을 `.claude/skills/zun-design/SKILL.md` 로
> 복사하면 클로드 코드가 알아서 읽습니다. `docs/` 에 두고 CLAUDE.md 에서
> 가리켜도 됩니다.

## 1. 색 — 이 블록을 그대로 복사하세요

```css
:root{
  /* 바탕 — 네 단계. 판 안에 판을 넣지 말고 **단계를 올려서** 구분합니다 */
  --bg:#0A0C10; --panel:#12141A; --panel-2:#171B24; --panel-3:#1F2534;

  /* 선 — 면을 가르는 것은 선의 일입니다 (테두리로 또 감싸지 않습니다) */
  --line:#1E2532; --line-2:#2E3849;

  /* 글자 — 세 단계뿐입니다. 네 단계를 만들면 위계가 안 보입니다 */
  --ink:#F2F4F8; --ink-2:#A9B2C4; --ink-3:#5F6B80;

  /* 강조 — 셋 다 계정의 시리즈 색이라 **새로 만든 색이 아닙니다** */
  --accent:#007EEC;      /* 면·띠 (N 시리즈 색 = 계정 강조색) */
  --accent-btn:#699EFE;  /* 버튼 바탕 (U 시리즈 색) */
  --accent-ink:#A7C2FE;  /* 링크·강조 글자 (Z 시리즈 색, 제일 밝은 쪽) */
  --accent-soft:#0E1E33; /* 강조 배경 (알림 띠·선택된 줄) */
  --on-accent:#05121E;   /* --accent-btn 위에 올리는 글자 */

  /* 상태 — 넷뿐입니다. 성공·주의·실패 말고 다른 뜻을 색으로 만들지 않습니다 */
  --ok:#4ade80;   --ok-soft:#122419;
  --warn:#fbbf24; --warn-soft:#2a2310;
  --bad:#f87171;  --bad-soft:#2a1618;

  --radius:14px; --radius-sm:10px;
  --gap:16px; --gap-lg:30px;

  --kr:"Pretendard Variable",Pretendard,-apple-system,BlinkMacSystemFont,
       "Apple SD Gothic Neo","Malgun Gothic",system-ui,sans-serif;
  --mono:ui-monospace,"SF Mono","JetBrains Mono",Menlo,monospace;
}
body{background:var(--bg);color:var(--ink);font-family:var(--kr)}
```

### 강조색이 셋인 이유

하나로 쓰면 자리마다 대비가 무너집니다. **재본 값**입니다 (배경 `--bg` 기준):

| 토큰 | 대비 | 쓰는 자리 |
|---|---|---|
| `--ink` #F2F4F8 | **17.8 : 1** | 제목·본문 |
| `--ink-2` #A9B2C4 | **9.2 : 1** | 설명·부제 |
| `--ink-3` #5F6B80 | **3.6 : 1** | 라벨·단위. **본문에 쓰지 마세요** (4.5 미달) |
| `--accent` #007EEC | 4.8 : 1 | 면·띠·테두리 |
| `--accent-btn` #699EFE | 7.4 : 1 | 버튼 바탕 |
| `--accent-ink` #A7C2FE | **11.0 : 1** | 링크·강조 글자 (작은 글자라 제일 밝은 쪽) |

⚠️ **`--accent` 위에 흰 글자를 올리지 마세요 — 4.04 : 1 로 미달입니다.**
버튼은 `--accent-btn` 바탕 + `--on-accent` 글자입니다 (**7.13 : 1**).
`--accent` 는 **글자를 안 얹는 면**(띠·테두리·그래프 막대)에만 씁니다.

### 밝은 배경을 쓸 거면

이 체계는 **어두운 쪽이 기본**입니다. 밝은 화면을 만들 거라면 강조색을
바꿔야 합니다 — `#007EEC` 는 흰 바탕에서 **3.8 : 1** 이라 작은 글자가
안 읽힙니다. 밝은 톤 강조색은 **`#006DCC`** 입니다 (모션 클립에서 같은
이유로 이미 쓰고 있는 값).

## 2. 안 하는 것 — AI 티가 나는 자리

이 목록은 취향이 아니라 **만들어보고 걷어낸 것들**입니다.

- **Inter 를 쓰지 않습니다.** 한글이 들어가는 화면에서 Inter 는 한글을
  대체 글꼴로 떨어뜨립니다. `--kr` 체인을 그대로 쓰세요.
- **보라색 그라데이션을 쓰지 않습니다.** 이 계정의 색은 **파랑 한 계열**
  (220° 근처)이고, 강조색 셋이 전부 거기서 나왔습니다.
- **둥근 카드에 드롭 섀도우를 겹치지 않습니다.** 어두운 바탕에서 그림자는
  안 보이고 테두리만 지저분해집니다. 구분은 `--line` 과 `--panel-2` 로.
- **판 안에 판을 넣지 않습니다.** 묶음은 **섹션 제목**이 합니다. 테두리로
  또 감싸면 「카드 안에 카드 안에 카드」가 됩니다.
- **유리 효과는 한 겹뿐입니다.** 하이라이트 한 겹만 남기고 테두리 링·
  헤일로·아랫변 반사는 만들어서 보고 **뺐습니다.** 얹을수록 짜쳐집니다.
- **빈 자리를 장식으로 채우지 않습니다.** 진행 막대·단계 점을 넣어봤다가
  걷어냈습니다 — 시간이 흐른다는 것 말고는 아무 주장도 안 하는 조각은
  **정보가 아니라 자리 메우기**입니다. 빈 자리에는 **왜 비었는지와
  다음에 뭘 하면 되는지**를 적으세요.
- **아이콘을 여러 세트에서 섞어 오지 않습니다.** 한 세트로 끝냅니다.

## 3. 글꼴

- 기본은 **Pretendard** 하나입니다. 제목만 굵게, 본문은 보통.
- 굵기는 **셋까지** — 400 / 700 / 800. 다섯 단계를 쓰면 위계가 흐려집니다.
- 코드·경로·명령어는 `--mono`. ⚠️ **모노 체인 끝에 한글 체인을 붙이세요** —
  모노 글꼴에는 한글이 없어서 기기마다 다른 글꼴이 나옵니다.
- **`word-break:keep-all`** 을 본문과 표에 거세요. 없으면 한글 낱말이
  줄바꿈에서 쪼개집니다.
- 숫자를 굴리거나 자리수가 바뀌는 칸은 **`font-variant-numeric:tabular-nums`**
  + 오른쪽 정렬. 안 하면 값이 바뀔 때 뒷말이 밀려 덜컹거립니다.

## 4. 모양

- 모서리는 `--radius`(14px), 작은 것은 `--radius-sm`(10px). **두 가지뿐.**
- 여백은 `--gap`(16px)·`--gap-lg`(30px)를 **토큰으로** 씁니다. 자리마다
  손으로 적으면 화면마다 밀도가 달라집니다.
- 세로 flex 로 칸을 나눌 때 **`min-height:0`** 을 같이 적으세요.
  기본값(`auto`)은 「내용보다 작아지지 마라」라서 글이 길면 칸이 상자 밖으로
  자랍니다 (실제로 그렇게 글이 잘린 채 저장됐습니다).
- **요소를 억지로 꽉 채우지 않습니다.** 다만 **쓰라고 만든 자리는 씁니다** —
  안전선까지 240~340px 이 비어 있는데 작아 보이던 적이 있습니다.

## 5. 배지·칩 — 유리 알약

시리즈나 주제를 나타내는 알약입니다. **한 모양으로 고정**입니다 (사진이
깔렸든 안 깔렸든).

```css
.badge{                      /* 시리즈 — 색이 꽉 차야 구분이 삽니다 */
  background:rgba(105,158,254,.72);   /* 시리즈 색 alpha .72 */
  color:#0A0C10;                       /* 밝기 0.34 초과면 어두운 글자 */
  border-radius:999px;padding:6px 14px;font-weight:800;
}
.chip{                       /* 주제 — 뒤가 보이는 게 칩의 일입니다 */
  background:rgba(255,255,255,.50);   /* 흰색 alpha .50 */
  color:#0A0C10;border-radius:999px;padding:6px 14px;font-weight:700;
}
```

- **알파의 바닥은 0.47 입니다.** 흰색을 알파 a 로 어두운 바탕에 얹으면
  실효 밝기가 대략 255a 이고, 어두운 글자와 4.5 : 1 을 넘으려면 a ≥ 0.47
  이어야 합니다. 그래서 칩이 **.50** 입니다.
- ⚠️ **대비는 「뒤에 무엇이 있나」에 따라 달라집니다.** 제일 어두운 바탕
  (`--bg` #0A0C10) 위에서 직접 재보면 **칩 5.3 : 1 · 시리즈 알약 4.3 : 1**
  입니다 — 시리즈 알약은 그 바탕에서 4.5 에 **살짝 못 미칩니다.** 사진이나
  밝은 판 위에서는 올라가지만, **어두운 배경에 작은 글자로 쓸 거라면
  알파를 .80 이상으로 올리거나 칩 쪽 스타일을 쓰세요.**
- 배지 **글자색은 바탕색의 밝기로 정합니다** — 밝기 0.34 초과면 `#0A0C10`,
  아니면 `#FFFFFF`. 흰색으로 못 박으면 밝은 색 배지에서 글자가 묻힙니다.
- 자간을 좁히는 것은 **영문일 때만**. 한글에 걸면 오히려 벌어집니다.
- 알파를 16진수로 이어 붙이지 마세요 (`#699EFEB8`) — 3자리 표기·`rgb()`
  에서 조용히 깨집니다. `rgba()` 로 만드는 함수 하나를 두세요.

## 6. 움직임

- **기본은 안 움직입니다.** 「정지를 피하려고 무언가 움직인다」는 이미
  걷어낸 것입니다. 자를 만족시키려고 장식을 넣는 것은 자를 낮추는 것과
  같은 일입니다.
- 움직여도 되는 것은 **값이 바뀌는 것**입니다 — 숫자가 올라가고, 막대가
  차고, 단계가 켜지는 것. 크기·자리만 흔드는 것은 장식입니다.
- 등장은 **제자리에서** (흐림·마스크). 이동·확대 계열 여섯을 만들어보고
  **뺐습니다** — 화면이 미끄러져 들어오면 그 순간 내용이 안 읽힙니다.
- 한 번 등장한 뒤 **사진·화면은 안 움직입니다.** 켄번스·팬은 시켰을 때만.
- 시간은 **한 번 등장 ≤ 800ms**, 퇴장은 등장의 75% 정도.
- `bounce`·`elastic` 이징은 안 씁니다. 등장 오버슈트는 `back.out(1.4~1.7)`
  까지.
- `will-change` 를 요소마다 걸지 마세요 — 래스터 전에 찍힌 프레임이 섞여
  글자가 통째로 빠진 장이 나왔습니다 (156장 중 7장).

## 7. 모바일

- 유입은 대부분 폰입니다. **폰 폭으로 먼저 만드세요.** CSS 중단점은 기기가
  아니라 **폭**을 봅니다 — 834px 는 태블릿 배치가 나옵니다.
- 좌우 여백 **16px** 을 비우고 가로 스크롤이 생기지 않게 합니다.
- 누르는 것은 **44×44px 이상**.
- 인스타에 화면이 나갈 거라면 **위 200px·아래 280px 은 UI 가 가립니다** —
  그 자리에 중요한 글자를 두지 마세요.

## 8. 캐릭터·워드마크

- 캐릭터는 **ZUN** — 큰 머리·작은 몸의 치비 비율, 짧은 검은 머리,
  큰 둥근 눈, 남색-검정 후디, 'ZUN' 이 박힌 남색 야구모자.
- 워드마크는 글자 **ZUN** 을 자간 `.4em` 으로. 시리즈에 따라 한 글자만
  켜고 나머지는 알파 `.88` 로 내립니다 (색 차이가 크면 눈이 두 덩어리로
  묶습니다).
- 캐릭터는 **분위기라 없어도 됩니다.** 근거 화면을 가리면 빼세요 — 실제로
  릴스에서 갈무리한 창을 가려서 껐습니다.
